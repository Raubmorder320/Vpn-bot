# Hamsterdam

Self-hosted VPN на Xray (VLESS + Reality) с Telegram-ботом, через который пользователи получают доступ по инвайт-кодам и смотрят свой трафик. Сервис работал на арендованном Linux VPS с апреля по сентябрь 2026 года. Сейчас весь проект поднимается одной командой через Docker Compose.

## Архитектура

```
Telegram ──► bot ──HTTP──► api ──gRPC :10085──► xray :443 ◄── VPN-клиенты
                            │
                            ├─ SQLite: пользователи и инвайты
                            └─ vnstat хоста: общий трафик сервера
```

- **xray** — VPN-сервер. Наружу открыт только порт 443, API Xray доступен лишь внутри docker-сети.
- **api** — управляющий сервис на FastAPI. Хранит пользователей и инвайты, генерирует ключи Reality и ссылки для подключения, собирает статистику трафика.
- **bot** — бот на aiogram для пользователей и администратора. Общается только с api.

## Как это работает

При первом запуске api создаёт конфиг Xray из шаблона, генерирует пару ключей Reality и записывает приватный ключ в конфиг. Xray стартует только после того, как api прошёл healthcheck и конфиг готов.

Новый пользователь регистрируется в боте по инвайт-коду. Api добавляет его в конфиг, проверяет конфиг через `xray -test` и применяет изменения к работающему Xray через его API. Перезапуск не нужен, соединения остальных пользователей не рвутся.

Каждые 10 минут бот запрашивает обновление статистики. Api забирает по gRPC счётчики трафика каждого пользователя и сохраняет их в базу. В начале месяца счётчики обнуляются.

Общий трафик сервера берётся из vnstat на хосте: его база монтируется в контейнер api только для чтения.

## Запуск

```bash
cp .env.example .env
# заполнить BOT_TOKEN, ADMIN_TELEGRAM_ID и SERVER_IP
docker compose up -d --build
```

Для статистики сервера в админке на хосте должен быть установлен vnstat: `sudo apt install vnstat`.
